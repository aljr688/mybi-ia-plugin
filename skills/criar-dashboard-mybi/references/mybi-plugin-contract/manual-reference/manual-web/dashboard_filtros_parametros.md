Permita que o usuário restrinja os dados exibidos no painel.

Escolha entre caixa de combinação, listagem, árvore, faixa e filtros de data. Parâmetros podem alimentar consultas e listas dinâmicas; seus nomes internos devem evitar espaços, acentos e caracteres especiais.

Valide a sintaxe dos parâmetros conforme o banco de dados e teste a consulta com valores válidos antes de publicar.
