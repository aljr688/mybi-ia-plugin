Componente "Cartão":

Como criar o componente de tipo "Cartão"

- Para criarmos o componente de tipo cartão, vamos no desenho abaixo e clicamos nele.

- Feito isso, só clicar no link para adicionar os campos.

- Exemplo do resultado final.

- Layout dos cartões:

Podemos alterar o layout do cartão clicando no componente de valor, após ter clicado, ir até Layout dos cartões.

Você terá algumas opções, segue a imagem abaixo como exemplo de layout

Temos a opção também de alterar o layout dos cartões.

Clicando no lápis do layout.

Após ter clicado no lápis, será aberto opções para editar esse layout, como editar a largura, se é personalizado ou não e etc..

- Podemos adicionar um Objetivo para o seu campo de cartões, como por exemplo custo

- Como formatar o valor para real

- Opções de formato

- Valor Real

- Dois cliques

- Formato de tipo > Real

- Unidade > Unidade

- Incluir separador de grupo > Ligado

Para cada valor você consegue editar o formato do valor

Minigráfico

- Para adicionar valor no campo minigráfico, tem que ser necessariamente do tipo data ou valor

Exemplo do minigráfico

- Podemos editar o layout desse minigrafico na parte de cartões > "Opções de minigrafico"
