Escolha a visualização adequada ao objetivo da análise.

O Dashboard Web oferece tabelas, gráficos, mapas, cartões, indicadores, imagens, páginas web e contêineres de layout. Em geral, crie o componente, associe dimensões e medidas e depois ajuste suas opções de exibição e interatividade.

Use tabelas e pivôs para detalhe, gráficos para comparação e tendência, cartões para indicadores resumidos e mapas quando a dimensão geográfica for relevante.
