# Contrato técnico sanitizado — MyBI IA 0.1.16

Snapshot histórico da coleta 0.1.16. Para suporte atual e ausência de defaults visuais,
consulte ../personalizacao.md e ../componentes-nativos.md (0.1.18). Os exemplos desta pasta não são padrões.

Base analisada: versão declarada 2.2.0, motor de dashboard 24.2.5.
Recorte confirmado: 16 componentes do gerador portátil e 7 configurações de título.
Não é um inventário completo dos componentes e recursos do MyBI.
Não contém código-fonte da aplicação, dados de clientes nem credenciais.
O plugin contém separadamente seu próprio serializador portátil, necessário à geração.

Consulte components-catalog.json para bindings e formatting-capabilities.json para
armazenamento e nível de suporte. Leia ini-contract.md e xml-contract.md antes de
gerar. manual-reference contém documentação pública offline; unknowns.md delimita
as lacunas. A auditoria privada não acompanha esta pasta.
