# Serialização

ZIP de dashboard: DashboardWeb/dashboard1.xml e formatacao.ini na raiz.
Ao ampliar dashboard existente, preservar o nome do XML, seu título, fontes,
parâmetros, consultas e componentes anteriores. Nunca recriar uma conexão real.
Identificadores de componentes devem ser únicos e todas as referências devem resolver.
Importação pode substituir o documento completo; a base exportada é obrigatória.
Não incluir backups, dados de clientes ou bibliotecas proprietárias no pacote.
